# xiaohongshu-note-extract

把**小红书图文笔记**的分享链接变成可读的素材：标题、正文，加上按页序排好的全部内容页原图。

## 为什么需要它

小红书这类"面经 / 面试题 / 教程"笔记有个共同特点：

> **正文只是节选，真正的内容全在图片里。**

直接在浏览器里"另存为"要么拿到一堆缩略图，要么把正文的中文弄丢。这个工具包把这几件事一次做对：

1. 短链自动跟重定向，拿到 `note_id` 与 `xsec_token`
2. 正确反转义 `desc` 字段（**中文不会被吃掉**）
3. 从多个 URL 变体里**只挑内容页大图**（过滤缩略图和装饰图）
4. 按页序命名输出，直接可以逐张阅读

## 快速开始

```bash
python scripts/xhs_fetch.py "<分享链接>" --out ./my_note
```

链接支持三种形式：

```
https://xhslink.cn/o/4jZDwSJjlOg                                  # 短链
https://www.xiaohongshu.com/discovery/item/<id>?xsec_token=...     # 长链（推荐）
6ad06c79000000000a01dc2f                                           # 裸 note_id（可能缺 token）
```

输出：

```
my_note/
├── desc.txt      标题 + 正文
├── URLS.txt      筛好的图片地址（按页序）
└── img/
    ├── 01.jpg
    ├── 02.jpg
    └── …
```

运行时会打印一份报告：

```
② 解析内容
   note_id : 6ad06c79000000000a01dc2f
   标题    : 运维工程师面试题：果使用Jenkins
   正文长度: 513 字
   候选图片: 17 个 URL
③ 下载图片
   策略: 优先 !h5 + MD5 去重
④ 结果
   img/  共 8 张
     01.jpg   60 KB
     02.jpg   192 KB
     …
```

## 关键要点

- **正文（desc）通常不是全文** —— 文字末尾出现 `……` 或 `【完整内容】↓↓↓` 时，内容在图片里
- **图片后缀会变**：内容页是 `!h5` 或 `!h5_1080jpg`，缩略图是 `!st`，装饰图是 `!style_<hash>`
  —— 用**包含** `!h5` 筛选，**不要用 `endswith`**
- **必须用 iPhone UA**，PC UA 拿到的 HTML 结构不同
- **`desc` 反转义必须用 `json.loads`**，用 `unicode_escape` 会把中文吃掉
- **体积能当信号**：内容页一般 >50 KB，缩略图只有几 KB

## 环境要求

- Python 3（仅用标准库，无需安装依赖）
- 无需登录、无需 Cookie

## 已知限制

- **视频笔记**内容在视频里，本工具只能拿到封面和正文
- 需要登录才能查看的笔记抓不到
- 裸 `note_id`（无 token）可能被拒 —— 用 App「复制链接」拿完整分享链接
